Data Analyst with a strong foundation in data wrangling, exploratory analysis, and practical machine learning. I turn messy, real-world data into clear insights and deployable solutions, not just notebooks.

I have hands-on experience selecting appropriate ML models, validating results, and deploying them on cloud services with basic monitoring for reliability over time.
